# 答疑与可行性判断

用于回答能力支持、接口用法、版本条件和方案可行性问题。

## 读取范围

使用 `rg` 在 `guide.md` 中检索问题里的能力名，并按需读取：

- 运行与打包：`运行环境`、`资源加载规则`、`支持的文件类型`
- 浏览器限制：`可用能力`、`已禁用的 Web API`、`已禁用的行为`
- 端能力：`调用约定`、`postNote`、`saveImageToPhotosAlbum`、`writeTempFile`
- 图形与依赖：`WebGL`、`WASM`、`Worker`
- 常见故障：`FAQ`、`CSP`、`window.xhs`、`网络请求`

## 判断方式

1. 将结论归为“支持”“有条件支持”或“不支持”。
2. 写明依据章节、前置条件和客户端版本要求。
3. 不支持时给出最接近的合规替代方案，不推断未记录的端能力。

完成时，结论必须能由已读取的指南原文直接支持。

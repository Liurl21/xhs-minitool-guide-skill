# 开发与修改

用于创建功能、修改代码、选择依赖或设计实现方案。

## 必读范围

1. 阅读 `guide.md` 的“运行环境”和“资源加载规则”。
2. 按实现内容读取相关端能力章节。
3. 阅读可能涉及的“已禁用的 Web API”“已禁用的行为”；图形任务另读“WebGL / 图形计算边界”。

## 实现检查

- 核对包内文件类型、资源路径、脚本引入与事件绑定方式。
- 确认所有资源离线可用，第三方依赖不联网且不使用禁用能力。
- 对 `window.xhs?.miniTool` 做能力检测，并按指南处理参数、Promise、回调、权限与失败路径。
- 为普通浏览器预览和未注入端能力的环境提供合理降级。

完成时，所有新增或修改的执行路径都必须符合已读取章节；无法合规实现的部分必须明确说明。

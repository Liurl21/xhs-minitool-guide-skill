# 审查与调试

用于代码审查、故障定位、第三方依赖兼容性检查和容器行为差异分析。

## 读取范围

- 局部故障：用错误信息、API 名或资源类型在 `guide.md` 中检索，只读相关章节与 FAQ。
- 全面审查：读取 `guide.md` 全文。
- 页面表现与 Markdown 描述冲突时，再查 `guide.html` 原文。

## 检查顺序

1. 区分普通浏览器问题与小红书容器限制。
2. 检查包内文件、资源加载、脚本策略、存储和浏览器 API。
3. 检查端能力是否存在、入参是否合规，以及 Promise、回调、权限和失败路径。
4. 检查依赖是否联网或使用动态代码、WebAssembly、Worker、外部资源等受限能力。
5. 按影响程度输出问题，并为每项引用指南章节和合规修复方向。

完成时，每个结论都必须对应可复现现象或明确的指南规则；仅在用户要求修复时修改代码。
